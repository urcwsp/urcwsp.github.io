# Shaopu Wang — GitHub Pages Personal Website

## Files
- `index.html` — main page
- `style.css` — styling
- `script.js` — mobile navigation and year
- `images/` — local artwork / paper thumbnails
- `cv.pdf` — put your own CV PDF here

## Deploy
1. Create a public GitHub repository named exactly `<your-github-username>.github.io`.
2. Upload all files in this folder.
3. Put your CV in the root as `cv.pdf`.
4. Replace the GitHub URL in `index.html` with your actual profile URL.
5. Replace publication `href="#"` placeholders with actual PDF/code/preprint URLs.
6. GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
7. Open `https://<your-github-username>.github.io`.

## Personal photo
The included `images/profile.svg` is a placeholder illustration. You can replace it with:
`images/profile.jpg`
and change the corresponding `src` in `index.html`.

## Privacy
The email shown on the site comes from the supplied CV. A phone number is intentionally not exposed by default on the public homepage; add it only if you want it public.
